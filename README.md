# SP-Operating-Systems
# Topic
Word and character counter 

Operating Systems project

In this project, we will be doing a word and character counter developed with the use of 
bash shell scripting in linux.

The purpose of this project is to create a menu-driven program that allows users to enter 
texts manually or load text from a file. This program will analyze the text and provide 
statistics such as word count (wc), character count, sentence count, paragraph count, and 
word frequency.

Steps to install and run the project
# Usage
The main objectives of our project are to:
- Allow users to enter text manually or load text from a .txt file
- Count words, characters, sentences, paragraphs, and lines
- Identify unique words and calculate word frequency
- Find the most common, longest, shortest words
- Calculate average word length
- Allow users to search for specific words
- Create a menu that’s interactive for navigating through the program
- Display texts statistics and save results to a file
